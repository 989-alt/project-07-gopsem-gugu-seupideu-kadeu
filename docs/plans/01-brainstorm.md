# Brainstorm — 곱셈구구 스피드 카드

> 사용자 질의 불가능한 무인 세션. AI 자체 판단으로 결정.

## 사용자 페르소나
- **주 사용자**: 초3~4 학생, 곱셈구구를 막 외운 단계. 자동화(즉답) 훈련 필요.
- **부 사용자**: 담임 교사 또는 학부모 — 학생 곁에서 결과 보고 약점 단(段) 파악.
- **환경**: 1:1 (한 학생이 한 기기에서 단독 사용). 학교 크롬북·태블릿·집 PC.

## 사용자 여정 (golden path)
1. 사이트 진입 → 단 선택 화면.
2. 2~9단 중 토글로 선택 (기본: 전체 선택).
3. "시작" 클릭 → 카드 화면. `7 × 8 = ?` + 숫자 입력.
4. 정답 입력 → 자동 다음 카드 (또는 Enter). 오답이면 빨간 깜박임 + 정답 표시.
5. 20문항 종료 → 결과 화면: 정답률, 평균/최단/최장 응답시간, 단별 정답률 그래프.
6. "오답만 다시" 또는 "다시 풀기" 또는 "결과 저장(PNG/인쇄)".

## MUST (꼭 필요한 기능, 3개 이상)
1. **단 선택 UI**: 2~9단 체크박스 + "전체" / "어려운 단만(6·7·8)" 프리셋. 최소 1개 단은 항상 선택돼야 함.
2. **무작위 출제**: 선택된 단 × 1~9 조합 셔플. 같은 문제 연속 출제 회피.
3. **즉시 채점 + 응답시간 측정**: 카드 표시 순간 `performance.now()` 시작, 답 입력시 종료. 각 문항별 ms 기록.
4. **세션 종료 결과**: 정답률 %, 평균 응답시간(초), 단별 정답률 막대그래프 (Chart.js).
5. **오답 재출제 모드**: 결과 화면에서 "틀린 문제만 다시" 버튼 — 오답 카드만으로 재세션.

## SHOULD (있으면 좋은 기능, 2개 이상)
1. **결과 PNG 저장**: 결과 화면을 캔버스로 그려 PNG 다운로드. (`html-to-image` 같은 외부 라이브러리 대신 자체 canvas 렌더로 의존성 0.)
2. **인쇄 친화 레이아웃**: `@media print` — 색·그래프 보존, 페이지 1장에 맞춤.
3. **세션 길이 선택**: 10 / 20 / 30문항 라디오. (기본 20.) 짧은 집중 훈련도 가능.
4. **키보드 단독 조작**: 숫자 키 + Enter만으로 전 과정. 마우스 없이도 빠른 풀이.
5. **직전 세션 비교**: localStorage에서 직전 결과 1개 보관 → "지난번 보다 +3% 빨라졌어요" 같은 1줄 피드백.

## MUST NOT (절대 금지 기능, 2개 이상)
1. **계정·로그인·서버 저장**: 학생 이름·번호·반 정보 일체 입력 받지 않음. localStorage 단독.
2. **학급 랭킹·등수 비교**: 다른 학생과 점수 비교 화면 없음. (자기 효능감 훼손 방지, 토픽 명시 배제.)
3. **사진·카메라·마이크 접근**: 권한 요청 자체 없음.
4. **광고·외부 트래커·analytics**: GA·픽셀·Hotjar 등 일체 미설치. CDN은 Chart.js 1개만.
5. **시간 압박형 카운트다운**: "3초 안에 답!" 같은 강제 타이머 금지. 응답시간은 측정만 하되 강제하지 않음(아동 부담 완화).

## scope creep 경고
- "단별 학습 모드" "AI 학습 분석" "보호자 리포트 메일" → 모두 OUT. 1일 1코딩 범위 초과.
- 결과 화면 그래프는 **단별 정답률 막대** 1개로 충분. 라인·파이·시계열은 과함.

## 성공 기준
- 5분 안에 학생이 도움 없이 1세션 완주 가능.
- 결과 화면에서 약점 단을 한 눈에 식별.
- console error 0건, P0·P1 버그 0건.
- 모바일(360px) ~ 데스크탑(1200px+) 모두 가독.
