## 색·타이포 결정

### 색
- 배경: `#ffffff`
- 텍스트 주: `#171717` (Vercel Black — 순수 검정 아님)
- 텍스트 보조: `#4d4d4d`
- 보조 텍스트(시간 등): `#666666`
- 테두리: shadow `rgba(0,0,0,0.08) 0px 0px 0px 1px`
- Primary CTA: 배경 `#171717` / 텍스트 `#ffffff`
- 정답 표시: `#0a72ef` (Develop Blue)
- 오답 표시: `#ff5b4f` (Ship Red)
- Focus ring: `2px solid hsla(212, 100%, 48%, 1)` (모든 interactive 요소)

### 타이포
- Family: `Geist`, fallback Arial. Geist는 Google Fonts에서 호스팅 가능 (또는 fallback Arial로 충분; 학교 크롬북 환경 고려).
- **CDN 차단 환경 대비 — Geist 로드 실패시 Arial fallback 작동**.
- 사이즈:
  - 큰 문제 (카드): 96px · 600 · letter-spacing -3px · tabular-nums
  - h1 (설정/결과 제목): 32px · 600 · -1.28px
  - h2: 20px · 600 · -0.4px
  - body: 16px · 400 · 1.5
  - 메트릭 숫자: 48px · 600 · -2.4px · tabular-nums
  - 작은 라벨: 12px · 500 (Geist Mono 느낌, uppercase는 한글 호환 안돼 미사용)

## 컴포넌트

### 단 토글 칩
- 크기 56×56px (터치 44px 이상 보장)
- 선택: 배경 `#171717` / 텍스트 `#ffffff`
- 미선택: 배경 `#fff` + shadow-border + 텍스트 `#171717`
- focus: 2px focus ring

### 프리셋 버튼
- 32px height pill (9999px radius)
- 배경 `#ebf5ff` / 텍스트 `#0068d6` (Vercel pill)
- 단 토글 상태 한 번에 변경

### 입력 box (카드 화면)
- width 200px height 96px (모바일에선 width clamp)
- 큰 숫자 입력 — `inputmode="numeric" pattern="[0-9]*"`
- 자동 focus, mobile 키패드 자동 호출
- 답 자리 수만큼 채워지면 자동 채점 (1자리 곱 결과는 최대 2자리: 9×9=81 → 9×1=9 까지)
  - 자리 수 처리: 입력 길이 ≥ 정답 자리 수가 되면 채점.

### Metric Card
- Vercel 카드 shadow stack 그대로
- padding 24px, radius 8px
- 라벨 12px #4d4d4d → 숫자 48px 600 #171717

### 차트
- Chart.js bar chart, 단(2~9) × 정답률(%)
- 색: 정답률 70% 이상 `#171717`, 50~70% `#666666`, 50% 미만 `#ff5b4f` (시각적 약점 신호)
- 격자 흐리게, 축 텍스트 12px #4d4d4d.

## 접근성 (WCAG AA)
- **대비**:
  - `#171717` on `#ffffff` → 16.6:1 (AAA)
  - `#4d4d4d` on `#ffffff` → 8.6:1 (AAA)
  - `#0a72ef` on `#ffffff` → 4.51:1 (AA pass for normal text — 18px 이상 권장)
  - `#ff5b4f` on `#ffffff` → 3.4:1 (큰 텍스트 한정. 24px 이상에서만 사용)
- **focus**: 모든 button·input·chip에 `:focus-visible` ring (2px solid #2989ff)
- **키보드**: Tab 순서가 시각 순서와 일치. Enter로 폼 제출 = 다음 카드.
- **aria**:
  - 각 단 토글: `aria-pressed="true|false"` + aria-label "2단 선택됨/해제됨"
  - 진행률 bar: `role="progressbar" aria-valuenow=3 aria-valuemax=20`
  - 카드 문제: `aria-live="polite"` 영역에 "다음 문제: 7 곱하기 8"
- **prefers-reduced-motion**: 흔들기·페이드 애니메이션 비활성화.

## 반응형
- 360px (모바일): 단 토글 4×2 그리드, 카드 화면 폰트 72px, 결과 메트릭 1열 스택.
- 768px (태블릿): 단 토글 4×2 또는 8×1, 메트릭 3열 유지.
- 1024px+ (데스크탑): 컨테이너 max-width 720px, 가운데 정렬.

## 인쇄
- `@media print`: CTA·진행률 hidden, 결과 화면만 단일 페이지로 정렬. Chart.js는 캔버스 → 인쇄 가능.
